# usage-band

Mod para Claude Code que dibuja una línea bajo el prompt con la sesión actual:

```
@usuario → ~/carpeta · rama │ Opus 5.5 │ Título del chat
```

También añade el modelo a cada fila de subagente del historial: `Agent(Buscar docs · Haiku 4.5)`.

El contexto, los límites de 5 horas y 7 días y la lista de subagentes están en el panel de
[open-sessions](../open-sessions).

## Instalación

```
/plugin install usage-band --marketplace ThomasPraun/claude-mods
```

Más opciones en el [README del repositorio](../../README.md).
